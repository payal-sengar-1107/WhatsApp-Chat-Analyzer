# 📱 WhatsApp Chat Analyzer

This is a **Python** based web application developed using **Streamlit** to analyze exported WhatsApp chat data (.txt format). It parses the raw text and visualizes insightful statistics through interactive charts and graphs.

## 🚀 Live Demo
You can check out the live working project here:
👉 **[Live Web App Link](https://payal-sengar-1107-whatsapp-chat-analyzer-app-coitcf.streamlit.app)**

## ✨ Key Features
- **Top Statistics:** Total messages, total words, media files shared, and links shared.
- **Monthly Timeline:** Tracks chat activity and message frequency on a month-to-month basis.
- **Daily Timeline:** Visualizes day-wise messaging trends.
- **Activity Map:** Identifies the busiest days of the week and months of the year.
- **Weekly Activity Heatmap:** Shows a detailed hour-by-hour heatmap of user activity.
- **Most Busy Users:** Highlights the top contributors in group chats along with their percentage share.
- **WordCloud:** Generates a visual representation of the most frequently used words.

## 🛠️ Tech Stack
- **Language:** Python 🐍
- **Frontend & Deployment:** Streamlit 🎈
- **Data Manipulation:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn, Wordcloud

## 💻 How to Run Locally
1. Clone this repository to your local machine.
2. Install the required dependencies:  
   `pip install -r requirements.txt`
3. Run the application:  
   `streamlit run app.py` *(or main.py depending on your setup)*
